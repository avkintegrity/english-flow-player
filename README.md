# English Flow Player

Простой автономный аудиоплеер для iPhone и компьютера. Без серверной базы, аккаунтов, аналитики и внешних библиотек. Пользовательское аудио не отправляется в GitHub или сторонние сервисы.

## Возможности

- Импорт из «Файлов»: MP3, M4A, WAV, AAC и другие форматы, кодек которых поддерживает устройство.
- Пауза, перемотка, скорость 0,75–2×, предыдущая/следующая запись, повтор записи или очереди папок.
- Переименование и удаление через кнопку ⋯; папки, приоритеты, заметки с автосохранением.
- Аудио и метаданные в IndexedDB. Последняя запись, позиция и скорость восстанавливаются при запуске; автовоспроизведения при открытии нет.
- Офлайн-оболочка PWA, иконки и все исполняемые модули в Service Worker.
- Полные резервные копии `.efp`: исходные аудиобайты, названия, папки, заметки, позиции и счётчики.
- Media Session для системных кнопок и совместимых Bluetooth-наушников; поддержка `audioSession.type = playback`, если доступна.

## Установка на iPhone

1. Откройте опубликованную HTTPS-ссылку в **Safari**.
2. Нажмите **Поделиться → На экран «Домой» (Add to Home Screen) → Добавить**. Если есть переключатель «Открывать как веб-приложение», оставьте включённым.
3. Запустите приложение **с новой иконки**. Загружайте аудио уже в установленном приложении: Safari и приложение с главного экрана могут использовать разные хранилища.
4. В ⚙ дождитесь «Приложение готово к работе без интернета».
5. Нажмите **+**, выберите аудио из «Файлов» и дождитесь сообщения о сохранении. Файл в iCloud сначала должен быть доступен для скачивания.
6. Для изменений используйте **⋯** рядом с записью. Нажатие названия открывает плеер; «Заметка» сохраняется автоматически, есть и кнопка «Сохранить».

## Резервная копия и хранение

В ⚙ нажмите «Подготовить резервную копию», затем **«Сохранить файл .efp»** или **«Поделиться / сохранить в „Файлы“»**. Сохраните копию вне приложения, например в iCloud Drive. Она содержит личное аудио и заметки и **не зашифрована**.

Восстановление: ⚙ → «Восстановить из файла .efp» → выбрать файл → подтвердить. Сначала проверяются структура, размер и CRC-32 каждого аудиофайла; затем вся библиотека добавляется одной транзакцией. Существующие записи не заменяются. Повторный импорт создаёт отдельные копии. При ошибке транзакция отменяется целиком. Во время импорта/экспорта держите приложение открытым.

Браузер может удалить локальные данные при очистке сайта, удалении приложения или нехватке места. Запрос устойчивого хранения уменьшает риск, но не заменяет копии. Приложение показывает приблизительную доступную квоту и обрабатывает ошибки заполнения. См. [политику хранилища WebKit](https://webkit.org/blog/14403/updates-to-storage-policy/).

Фоновое воспроизведение, экран блокировки, переход к следующему файлу в фоне и AirPods зависят от версии iOS и ограничений системы. Проверка на физическом iPhone обязательна; она не заменяется тестами Safari на Mac.

## Локальный запуск и тесты

Проект не требует установки пакетов или сборки. Открывайте его через HTTP-сервер, а не `file://`:

```sh
npm start
```

Откройте `http://127.0.0.1:8080/`. Для PWA вне localhost нужен HTTPS.

```sh
npm test
npm run check
```

В браузере откройте `/browser-tests.html` для тестов реальной IndexedDB. Они создают отдельную случайно названную тестовую базу и не изменяют пользовательскую библиотеку. Результаты и оставшиеся ручные проверки описаны в [TESTING.md](TESTING.md).

## GitHub Pages и обновления

Отдельный репозиторий `english-flow-player`, ветка `main`, **Settings → Pages → Deploy from a branch → main / (root)**. Файл `.nojekyll` отключает обработку Jekyll. Относительные URL, `scope`, `id` и `start_url` рассчитаны на размещение в `/english-flow-player/`.

При изменении файлов оболочки увеличивайте `VERSION` в `sw.js`. Новая оболочка устанавливается полностью и ждёт нажатия «Сохранить и обновить». Перед активацией сохраняются заметка и позиция. Удаляются только прежние кэши данного пути; IndexedDB не очищается. Старые вкладки могут продолжать предыдущую версию до повторного открытия.

Схема IndexedDB v2 сохраняет имя исходной базы `english-flow-db` и атомарно переносит Blob из записей v1 в отдельное хранилище `audio`. Редактирование метаданных больше не переписывает большие аудиофайлы.

Для большого архива CRC-32 вычисляется по блокам 1 МБ. Контрольная сумма обнаруживает случайное повреждение; она не является криптографической подписью. Предел JSON-манифеста — 8 МиБ и до 10 000 записей/папок; общий размер аудио ограничен возможностями браузера и доступным местом.
