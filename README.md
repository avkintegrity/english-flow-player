# English Flow Player 2.1.1

Автономный аудиоплеер для iPhone и компьютера. [Открыть приложение](https://avkintegrity.github.io/english-flow-player/). Без аккаунта, аналитики, серверной базы и внешних библиотек. Аудио, заметки и резервные копии не отправляются на сервер.

## Библиотека и воспроизведение

- MP3, M4A, WAV, AAC и другие форматы с поддерживаемым устройством кодеком; импорт через «+» из приложения «Файлы».
- Выбор кнопкой или долгим нажатием, выбор всех видимых записей, групповые папки, приоритет и удаление с подтверждением количества.
- Несколько папок у одной записи без дублирования аудио. В групповом редакторе «−» означает назначение части записей; меняются только явно затронутые папки. Удаление папки сохраняет аудио.
- Закрепление удерживает запись сверху; приоритет отмечает звездой и добавляет в отдельный раздел, не меняя порядок. Разделы «Нужно переслушать» и «Хорошо» сохранены.
- Свайп вправо открывает закрепление, приоритет и «Играть следующей»; влево — папки, название и удаление. Те же действия есть в «⋯». Свайп сам ничего не удаляет.
- Шесть сортировок: дата, размер в байтах и количество прослушиваний — в обоих направлениях. Порядок не пересчитывается при Play/Pause или обновлении счётчика.
- Очередь хранится отдельно от списка. Shuffle и 1/2/3/∞ проходов независимы. В автоматическом проходе нет повторных ID; «Назад» идёт по истории. Ручной запрос повторить уже звучавшую запись отделён от автоматического прохода.
- Отдельный повтор текущей записи явно приостанавливает продвижение списка. Автозапуска после открытия приложения нет.
- Перемотка в мини-плеере, крупная Play/Pause, скорость 0,75–2×, позиции и состояние очереди сохраняются.
- Новое прослушивание засчитывается один раз за проход при 90% уникальных реально воспроизведённых участков (`HTMLMediaElement.played`). Перемотка и повтор короткого фрагмента не заменяют прослушивание. Старые счётчики сохранены; точная логика действует с версии 2.
- «Сохранить» записывает заметку, убирает клавиатуру и сворачивает редактор. Автосохранение согласовано с этой кнопкой. Панели закрываются снаружи, ручкой, кнопкой или Escape; незавершённый ввод защищён.
- Нажатие «English Flow RU/EN» меняет язык интерфейса и сохраняет выбор. Названия, папки и заметки не переводятся.
- «Текст»: синхронные EN/RU, поиск, редактирование, переход по предложению, повтор, цикл и пауза. Импорт `.eftext` сверяет SHA-256, размер и длительность.
- «Фразы»: контекстный словарь, сохранение выражений, «Уже знаю», исходное аудио и локальный голос US. [Инструкция](PHRASES.md).
- Отдельный [инструмент Mac](local-ai/README.md) готовит текст, перевод и словарь локально. Перевод требует вычитки; PWA не запускает модели и не передаёт аудио в облако.

## Установка и обновление на iPhone

1. Откройте сайт в Safari → **Поделиться → На экран «Домой» → Добавить**.
2. Запустите приложение с иконки. Импортируйте аудио именно там: Safari и установленная PWA могут использовать разные хранилища.
3. В ⚙ дождитесь сообщения о готовности офлайн-режима; затем добавьте файл через «+». Файл из iCloud должен быть сначала скачан на устройство.
4. Для обновления существующей установки подключитесь к интернету и откройте приложение. После появления предложения обновиться поставьте аудио на паузу, сохраните и сверните заметку, нажмите **«Сохранить и обновить»**.
5. Проверьте в ⚙ **версию 2.1.1**. Переустановка и очистка данных сайта не требуются. Если предложение ещё не появилось, закройте и снова откройте приложение с интернетом.

Новая оболочка сначала полностью кэшируется и ждёт действия пользователя. Кнопка обновления блокирует перезагрузку при воспроизведении, открытом редакторе заметки или операции с библиотекой. Активируются только ресурсы приложения; IndexedDB не очищается.

## Хранение и резервные копии

Имя базы `english-flow-db`, origin и идентичность PWA сохранены. Миграция v1/v2/v3→v4 переносит прежнюю одиночную папку в `folderIds`, сохраняет исторические счётчики, приоритет, заметки, позицию и аудио. Blob хранится отдельно от метаданных и не дублируется между папками.

В ⚙: «Подготовить резервную копию» → «Сохранить файл .efp» / «Поделиться». Копия содержит аудио и личные данные, не зашифрована; храните её вне приложения, например в «Файлах»/iCloud Drive.

Новый манифест `.efp` v3 сохраняет несколько папок, закрепление, приоритет, покрытие прослушивания, данные фраз и настройки/очередь. Импорт старых `.efp` v1/v2 поддерживается. Проверяются структура, размеры и CRC-32; восстановление добавляет данные одной атомарной транзакцией, не заменяя существующие записи. Повторный импорт создаёт отдельные копии. Настройки из копии применяются только к пустой библиотеке. Старые версии приложения не обязаны читать новый формат.

При восстановлении части исходного File материализуются блоками по 1 МиБ перед IndexedDB: это предотвращает обнаруженную в Safari потерю смещения аудио внутри архива. JSON-манифест ограничен 32 МиБ и 10 000 записей/папок. Во время импорта и экспорта держите приложение открытым.

Браузерное хранилище может быть удалено при очистке данных сайта, удалении приложения или нехватке места. Запрос устойчивого хранения уменьшает риск, но не заменяет резервную копию. [Политика хранилища WebKit](https://webkit.org/blog/14403/updates-to-storage-policy/).

Используются один HTML audio, Media Session и, при наличии, `audioSession.type = playback`. Фон, экран блокировки, переходы между файлами и AirPods требуют проверки на физическом iPhone; результаты настольных браузеров этого не подтверждают.

## Разработка и проверки

Без установки зависимостей и сборки:

```sh
npm start
npm test
npm run check
```

Приложение: `http://127.0.0.1:8080/`. Вне localhost необходим HTTPS. `browser-tests.html` проверяет реальную IndexedDB в случайных отдельных тестовых базах. `media-tests.html` запускается кнопкой и проверяет нативное воспроизведение созданного в браузере WAV. Оба набора используют только синтетические данные и не отправляют их наружу. Подробности: [TESTING.md](TESTING.md).

GitHub Pages: `main / (root)`, `.nojekyll`, все URL относительные. При изменении оболочки синхронно увеличивайте версии в `app.js`, `sw.js`, `package.json`. Service Worker обновляет только кэши своего пути, не трогая другие приложения и пользовательскую базу.
